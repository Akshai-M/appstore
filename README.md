# Product Listing Application

This project is a React-based web application for listing and filtering products. It is built using Vite for fast development and Tailwind CSS for styling.

## Features

- **Product Listing**: Displays a grid of products fetched from an API.
- **Filtering**: Allows users to filter products based on various criteria.
- **Sorting**: Provides options to sort products by name, price, or date.
- **Responsive Design**: Fully responsive layout for desktop and mobile devices.
- **Context Management**: Uses React Context API for authentication and cart management.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Akshai-M/appstore.git
   ```

2. Navigate to the project directory:
   ```bash
   cd project
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open the application in your browser at `http://localhost:5173`.

## Scripts

- `npm run dev`: Starts the development server.

## Technologies Used

- **React**: JavaScript library for building user interfaces.
- **Vite**: Fast development build tool.
- **Tailwind CSS**: Utility-first CSS framework.
- **React Router**: For routing and navigation.
- **Axios**: For making API requests.
